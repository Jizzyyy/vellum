# Vellum

A privacy-first, on-device smart document scanner and OCR engine built with Flutter.

## Features
- 📸 **Live Viewfinder & Guide:** Auto-detects paper orientation and alignment with real-time accelerometer feedback.
- ⚙️ **Image Filtering:** Grayscale conversion and threshold contrast filters to simulate scanned documents.
- 🔍 **On-Device OCR:** Extracts texts 100% offline using Google ML Kit.
- 📂 **PDF Generation & Vault:** Encodes photos into multi-page PDFs, saves documents into a persistent Local Vault, and shares via Native OS Share Sheet.

## Getting Started

```bash
flutter pub get
flutter run
```
